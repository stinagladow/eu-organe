# Wer entscheidet in der EU?

Interaktive Lernstation für Politik und Gesellschaft, Q12: Aufbau und Zusammenwirken der EU-Organe (Europäisches Parlament, Kommission, Europäischer Rat, Rat der EU), ordentliches Gesetzgebungsverfahren sowie Verordnung, Richtlinie und Beschluss.

Eine einzelne Datei (`index.html`), läuft ohne Server direkt im Browser. Fortschritt wird im Browser gespeichert.
